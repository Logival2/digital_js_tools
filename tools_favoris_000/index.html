Confidentialité · Sécurité

Tes favoris

L'export Firefox est lu uniquement dans ton navigateur. Seuls les deux dossiers choisis sont transformés en ressources.json ; le reste de tes favoris ne quitte jamais ton ordinateur.

Token GitHub

Le token est chiffré avec ton mot de passe (PBKDF2, 600 000 itérations, puis AES-GCM 256 bits) et seul le résultat chiffré est gardé dans ce navigateur (localStorage). Il est déchiffré au moment de l'envoi, utilisé une fois, puis oublié. Utilise un token « fine-grained » limité au dépôt digital_js_tools, permission Contents en lecture/écriture, avec une date d'expiration.

Services tiers

  • GitHub (api.github.com) — reçoit uniquement ressources.json, avec ton token ;
  • Google Fonts — police d'interface.
