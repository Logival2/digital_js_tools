Privacy · Security

Data controller

Valentin Maynadié — contact: valentinmaynadie@gmail.com

Your bookmarks

The Firefox export is read only in your browser. Only the two chosen folders become ressources.json; the rest of your bookmarks never leaves your computer.

GitHub token

The token is encrypted with your password (PBKDF2, 600,000 iterations, then 256-bit AES-GCM) and only the encrypted result is kept in this browser (localStorage). It is decrypted when you send, used once, then forgotten. Use a fine-grained token limited to the digital_js_tools repository, with Contents read/write permission and an expiry date.

Cookies and tracking

This site uses no cookies, no analytics and no user accounts. Fonts are served with the page.

Third-party services

  • GitHub (api.github.com) — receives only ressources.json, with your token.

GitHub receives your IP address, which it needs to answer.

Your rights

This site keeps no personal data. For any question about your rights (access, rectification, erasure, objection), write to the address above. You can also contact the CNIL, the French data protection authority (cnil.fr).
